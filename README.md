# Glen Cooney's Portfolio Page

Built using Jekyll and the [Moon](http://taylantatli.me/Moon/) theme.

# Running Locally

-   Update `_config.yml:13` to use localhost instead of github pages
-   Run locally with `bundle exec jekyll serve` or alias `rjek`
-   Revert change to `_config.yml` back to github pages url
